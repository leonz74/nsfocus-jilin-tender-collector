标书采集平台 · NSFOCUS 吉林代表处，v0.3.0

| 系统 | 分发包 | 首次运行 |
|---|---|---|
| Mac，Apple Silicon / Intel，macOS 11 及以上 | NSFOCUS-TenderCollector-v0.3.0-macOS-universal.zip | 完整解压，双击“标书采集平台.app” |
| Windows 10 / 11，Intel / AMD 64 位 | NSFOCUS-TenderCollector-v0.3.0-Windows-x64.zip | 右键“全部解压”，双击“安装并启动.cmd” |

安装过程自动放置程序、创建桌面快捷方式并打开网页。以后双击桌面“标书采集平台”即可运行；双击“停止标书采集平台”可退出并保留已采集结果。

两个包都内置 Python 和所需依赖，不需要手动安装 Python、Node、pip 或开发工具。安装不需要管理员权限，运行环境部署不需要联网；查询网站和使用 AI 需要联网。

首次需要使用自己的账号、Key 和网站登录状态。AI 默认关闭；导航网已预置，需在来源配置中启用并登录。验证码由用户在 Edge / Chrome 中完成；没有这两种浏览器时，需要先安装一种。Mac 可在界面保存 Key；当前 Windows 版使用临时 Key 或环境变量，尚不支持持久保存 Key。

Mac 为内部签名包，尚未经过 Apple 公证；首次运行可能需要按系统“隐私与安全性”的提示允许打开。

Mac 已完成本机实际安装、启动、采集、导出、停止和重启验证。Windows 已完成打包与静态检查，尚未在 Windows 实机上验证。详细范围见“打包验收说明.md”。

程序更新与数据存储分开。更新前先停止平台，再运行新版安装入口。包内“使用说明.txt”包含数据位置、故障日志位置和卸载方式。校验值见 SHA256SUMS.txt。
