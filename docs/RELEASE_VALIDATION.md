网站验证与功能范围：本次真实采集测试用于确认分发版可以启动采集子进程并导出；未重新全量验收所有平台。导出中的附件 URL 仍有“未验证下载”等获取说明，不能视为附件已经下载，也不能证明不存在漏报。登录、验证码、会员权限和网站限流仍按现有功能处理。
